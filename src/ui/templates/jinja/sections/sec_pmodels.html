Static routing the chain the gateway walks

This ordered chain is a circuit-breaker pattern: every request tries link 1 first, and when a link fails — provider down, key invalid, breaker tripped — the gateway falls through to the next link, in this order, until one serves. Order is fallback priority: top of the list is the preferred model, every link below it is the escape route. {% if pool.routing_on %} Dynamic routing is on for this profile, so the router may reorder these links per request; when it is off (or no better model scores), the breaker walks this list exactly as shown. {% elif pool.routing_on is none %} The router's state for this profile is unknown from here. {% else %} Dynamic routing is off for this profile, so requests walk this list top to bottom. {% endif %} A link can be taken out of rotation without deleting it — toggle it off and the breaker skips it.
